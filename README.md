# GitHub Achievements & Badges

A repository to track and unlock GitHub profile achievements.

## Achievements Overview

| Achievement | Description | Tiers |
|---|---|---|
| 👯 **Pair Extraordinaire** | Co-authored a commit merged via a Pull Request | Bronze, Silver, Gold |
| 🦈 **Pull Shark** | Opened a pull request that was merged | Bronze, Silver, Gold |
| 🚀 **YOLO** | Merged a pull request without code review | Single Tier |
| ⚡ **Quickdraw** | Closed an issue or PR within 5 minutes | Single Tier |
| 🧠 **Galaxy Brain** | Answer marked as accepted in GitHub Discussions | Bronze, Silver, Gold, Diamond |
| 🌟 **Starstruck** | Repository reached a star milestone | Bronze, Silver, Gold, Diamond |
| 💖 **Public Sponsor** | Sponsored an open-source contributor | Single Tier |
